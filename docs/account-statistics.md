# Codex 账号服务端使用统计

使用统计提供两类独立数据：本机 JSONL 记录，以及当前登录账号的服务端活动数据。两者的范围、时间和指标可能不同，不相加、不相互补零。

## 来源选择

在 Codex 使用统计或偏好设置选择来源：

- **本机记录**：沿用今日／本周／本月／本年／全部的本地统计和缓存。
- **服务端**：程序根据本机登录态自动选择可用的认证和查询方式，按今日／本周／本月／本年／全部展示当前账号的服务端 Token 活动和每日记录。

默认仍为本机记录。界面不提供或显示 OAuth、PAT、CLI 等认证方式。旧设置缺少新增字段时，恢复为 `codexStatisticsSource: local`、`codexWebExtras: false`；旧版显式指定的 `oauth`、`pat`、`cli` 来源统一迁移为 `auto`（界面显示“服务端”）。来源和账号变更会使正在返回的旧服务端请求失效；无法确认缓存属于当前登录范围时，不展示旧账号的服务端结果。

## 本地缓存与刷新

以下行为仅适用于服务端来源，本机记录的加载与刷新方式保持不变。

- 成功采集的账号统计原子写入 `~/.agent-bar/codex-account-statistics.json` 并读回后才展示。只缓存归一化的成功数据，不缓存凭据、Cookie 或接口原始响应；目录权限 `0700`，文件权限 `0600`。成功的网页补充数据可一起保存，网页错误提示仅在当次采集展示。
- 启动先读缓存。存在有效缓存时直接展示，不立即发起服务端请求；没有缓存、缓存损坏或登录范围不匹配时，才静默获取服务端数据。无缓存的自动获取显示简短状态提示，不使用面板 loading。
- 桌面独立 `statistics` 窗口在启动时预创建并常驻，由它唯一持有服务端统计 store，按设置的 1／5／15 分钟周期自动刷新；隐藏窗口不卸载刷新生命周期。自动刷新保留当前缓存和原始采集时间，仅刷新按钮旋转，成功后替换数据。展开面板不会重复触发请求，也不受额度快照更新驱动。
- 点击统计刷新按钮、网页“返回后刷新”、Codex 卡片刷新或托盘“刷新用量”时，才显示服务端面板 loading。若后台请求已经进行，手动操作复用该请求并切换加载反馈，不重复请求。
- 刷新失败重新核验磁盘缓存：仍属于当前登录范围的成功数据继续显示，并提示更新失败；无有效缓存则显示错误。失败与无数据响应不覆盖成功缓存，旧请求不能覆盖更新请求。

缓存包含当前 Codex home、登录文件和配置的不可逆范围摘要；这些内容发生变化时重新采集，避免混用账号或后端。缺失或不可读取登录信息时不会复用空范围缓存；服务端仍能返回数据时可以当次展示，并提示未缓存。关闭网页补充时不恢复已缓存网页数据。桌面主窗口和设置窗口不重复启动统计轮询；卡片与托盘通过刷新事件交给统计窗口处理。

统计窗口使用 `index.html#statistics`，关闭时隐藏并复用。`useAccountStatistics` 统一管理初始化、定时刷新、手动事件与账号生命周期；设置和账号通过原生事件同步。macOS 14 及以上禁用该 WebView 的后台节流，使隐藏期间仍可处理刷新和显示前的渲染确认；其他平台及系统版本的隐藏执行时机仍受 WebView 能力影响。浏览器预览保留页内统计，不创建原生窗口，也不读取真实账号数据。

## 自动查询机制

内部优先使用可用的 PAT，再使用 OAuth；原生认证需要恢复时，按受控策略使用同一 `CODEX_HOME` 的官方 CLI。PAT 先通过 `whoami` 确认身份，不混用 OAuth 的账号头；OAuth 使用本机凭据直接查询服务端；CLI 通过 `account/read`、`account/usage/read` 读取官方 app-server 归一化数据。网络错误、服务端错误和限流不会触发额外 CLI 请求。

## 账号 Token 活动

直接接口是 `GET https://chatgpt.com/backend-api/wham/profiles/me`。参考 [OpenAI Codex `e22e6523` 的 backend-client](https://github.com/openai/codex/blob/e22e6523eb5b87f1872e823fa6c97906c2fc671a/codex-rs/backend-client/src/client.rs#L358) 与 [官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)。

按接口实际返回显示累计 Token、单日峰值、最长任务时长、当前连续活跃天数、最长连续活跃天数，以及 `daily_usage_buckets` 按日记录。`metadata.stats_as_of` 是服务端数据时间；采集时间单独展示。字段缺失显示 `—`，真实零值保留为 `0`。

服务端默认选择今日，与本机记录共用五时段切换控件。切换仅对当前服务端快照重新汇总，不发起额外请求：

- **今日／本周／本月／本年**：根据本地当前日历计算起止日期，周一为每周起点，本年从 1 月 1 日开始，截止日期包含今日。按服务端 `YYYY-MM-DD` 日期原样筛选，不转换日记录的时区；未来日期不纳入。Token 合计与单日峰值仅根据所选范围已返回的记录计算，并标明可能不完整。
- **全部**：Token 总量与单日峰值使用服务端 `lifetimeTokens`、`peakDailyTokens` 汇总，字段缺失仍显示 `—`，不以有限每日记录的合计替代全部历史。每日列表展示截至今日已返回的所有日期。
- 日记录缺失、返回空数组或所选范围没有匹配日期时，不伪造零用量；存在明确的零值记录时才显示 `0`。列表仅保留已返回日期。
- 最长任务时长与连续活跃天数单独放在“账号活动概览”，不随时段切换。服务端更新日期不改变“今日”的日期含义；服务端数据落后时，今日可以显示尚未返回。

该接口未承诺日记录的完整覆盖长度或日界线时区。页面使用服务端日期，不把缺失日期补成零，不把返回区间当作全部历史。它没有提供本机统计所需的完整模型、输入／输出／缓存、请求数或单价明细，因此不会据此推算约等金额。

## 可选网页补充

网页补充默认关闭。开启后，点击连接按钮打开独立的 ChatGPT 网页窗口；登录由用户在官方网页完成。它不导入其他浏览器 Cookie，不把 Cookie、access token 或原始网页内容传到 React。

网页会话仅在本次应用运行中保留。窗口关闭按钮隐藏窗口以便复用；关闭网页补充或退出 AgentBar 后需重新连接。未打开或未完成登录时，统计会明确显示连接提示，不在后台自动打开登录窗口。

读取前核对网页账号与服务端已确认的账号。网页通过同源接口和已登录页面取得：

- Credits 余额；代码审查剩余百分比按页面中的明确标签提取，页面未提供时保留为空。
- 近 30 个 UTC 日期的使用分布：`/backend-api/wham/usage/daily-token-usage-breakdown`。
- Credits 记录：`/backend-api/wham/usage/credit-usage-events`。

接口名包含 `token` 不代表每一个数值的单位都是 Token。使用分布必须依据服务返回的 `units` 标注；未知单位不会被改写成 Token。Credits 记录允许负值（例如调整或退款），不强行截为零。某一项读取失败时保留其他成功项并标记不完整，全部失败则报错。

这些是账号页面的补充指标，不随上方时段切换，也不加入本机 Token 或美元估算。每日使用分布及 Credits 记录采用官方已声明的分析接口，避免依赖表格和图表 DOM；代码审查额度保留基于明确页面标签的提取方式。
